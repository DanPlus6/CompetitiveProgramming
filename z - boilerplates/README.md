# Boilerplates

In this directory I keep my competitive programming boilerplates for the main languages I use for competitive programming.
These boiler plates are empty/skeleton programs that should provide one with most of the base/universal macros and optimizations they need to write any competitive programming solution.

## .json files 🤨

The .json extension files that have a language name as the filename are the VS code snippet versions of my code boilerplates. For more information on VS code snippets and how to add/configure them, see [VS Code Documentation](https://code.visualstudio.com/docs/editing/userdefinedsnippets).
