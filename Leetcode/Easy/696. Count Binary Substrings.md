# Intuition
Problem description is wordy, but basically we must find number of substrings with symmetrical number of 0s and 1s next to each other.

For example:
`0011` is symmetrical because it has 2 `0`s on the left and 2 `1`s on the right

# Approach
## Definitions
Use sliding window
The contiguous subarray/substring where each element is the same value is our window (ex: in "1000111", the substrings `1`, `000` and `111` are all windows)
## Algorithm
- only need three variables, `prev_sz` tracks previous window size, `cur_sz` tracks current window size and `res` to store our answer
- Iterate through the string and track size of current and previous window
    - if current element is same as last, increment `cur_sz`
    - else if encounter different element from our current window, set `prev_sz` to `cur_sz`, then set `cur_sz` to 1
    - check if `cur_sz` $\le$ `prev_sz`, if so, increment `res`

```cpp []
/**
 * Author: DanPlus6 // David Fu
 * Problem Name: 696. Count Binary Substrings
 * Problem Code: count-binary-substrings
 * Problem URL:  https://leetcode.com/problems/count-binary-substrings/description

#include <string>
using namespace std;

class Solution {
public:
    int countBinarySubstrings(string s) {
        int res = 0;
        for (int prev_sz = 0, cur_sz = 1, i = 1; i < s.length(); ++i) {
            if (s[i] == s[i-1]) ++cur_sz;
            else {
                prev_sz = cur_sz;
                cur_sz = 1;
            }

            if (cur_sz <= prev_sz) ++res;
        }

        return res;
    }
};
```

```python []
class Solution:
    def countBinarySubstrings(self, s: str) -> int:
        res = prev_sz = 0
        cur_sz = 1
        for i in range(1,len(s)):
            if s[i] == s[i-1]: cur_sz += 1
            else:
                prev_sz = cur_sz
```

```java []
/**

 * Problem Name: 696. Count Binary Substrings
 * Problem Code: count-binary-substrings
 * Problem URL:  https://leetcode.com/problems/count-binary-substrings/description

class Solution {
    public int countBinarySubstrings(String s) {
        int res = 0;
        for (int prev_sz = 0, cur_sz = 1, i = 1; i < s.length(); ++i) {
            if (s.charAt(i) == s.charAt(i-1)) ++cur_sz;
            else {
                prev_sz = cur_sz;
                cur_sz = 1;
            }

            if (cur_sz <= prev_sz) ++res;
        }

        return res;
    }
}
```

# Complexity
- Time complexity: $O(n)$

- Space complexity: $O(1)$
